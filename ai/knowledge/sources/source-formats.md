# Source Formats

- Six `SOURCE_VARIANTS` covering five agents (codex appears twice). Source: `contract.constants.ts`, lines 61-104.
- `jsonl_append` + `byte_range` watermark: Claude Code (`*/*.jsonl`), Codex rollouts (`sessions/*/*/*/rollout-*.jsonl`), Claude Desktop (`*/*/local_*/audit.jsonl`).
- `sqlite_kv_snapshot` + `rowid_range`: Cursor (`state.vscdb` files — global + per-workspace). Key prefix allow-list: `composerData:`, `bubbleId:`, `agentKv:blob:`.
- `sqlite_table_snapshot` + `rowid_range` + `watermark_table`: Codex state (`state_*.sqlite`, highest-numbered only; table allow-list `threads`, `thread_spawn_edges`); and Gemini/Antigravity (`*.db` Cascade trajectory DBs; table allow-list `trajectory_meta`, `steps`, `trajectory_metadata_blob`).
- Gemini (`gemini`) is the Antigravity source. One source, two roots: `~/.gemini/antigravity-cli/conversations/*.db` → `source_platform = antigravity-cli`; `~/.gemini/antigravity-ide/conversations/*.db` → `source_platform = antigravity-ide`. Gemini Desktop has no local conversation data (out of scope); legacy `.pb` siblings and the old Google Gemini CLI are out of scope. Each `steps` row's `step_payload` is a **protobuf** blob that the gateway decodes to plaintext (`proto-scan.ts` + `step-decode.ts`) **before** redaction, so the redactor sees real message text. `agent_schema_version` is the hard-coded `antigravity/1.0.0` (no upstream version string). Detail: [antigravity-format.md](./formats/antigravity-format.md), [gemini.md](./parsers/gemini.md).
- Claude Desktop (`claude-desktop`) is the GUI "Cowork" source (macOS-only, `~/Library/Application Support/Claude/local-agent-mode-sessions`). It watermarks the authoritative `audit.jsonl` and enriches each kept record with CLI metadata correlated from the session's `.claude/projects/*/*.jsonl` transcript (`user` by `uuid`, `assistant` by `message.id`), then renames audit keys (`session_id`→`desktopSessionId`, `client_platform`→`clientPlatform`) and injects `source_platform = 'claude-cowork-desktop'`. Reuses claude-code's `isDialogueRecord` plus an `isReplay === true` drop.
- Cursor reads use `snapshotSqlite` (Bun snapshot API) to avoid blocking the live writer. Codex state opens read-only with a double-attempt fallback: if `openReadOnly` throws, retry with `{ immutable: true }`.
- Codex rollout discovery pre-queries `thread_spawn_edges` from the state sqlite to build a set of child-thread rollout paths and skips them by default (sub-agent flag off). Errors opening the state DB produce an empty set (fail-open).
- Agent schema version detection: claude-code parses `version`/`message.version` from kept lines; claude-desktop uses the correlated File A `version` prefixed `claude-desktop/` (fallback `unknown`).
- VACUUM detection (for sqlite sources): `detectVacuum` in `services/buffer/vacuum-detect.ts` triggers on any of: `size_decreased`, `page_count_decreased`, `rowid_regressed`. On trigger, source path gets `#gen-N` suffix + rehash; fresh cursor at `watermark_end = 0`.
